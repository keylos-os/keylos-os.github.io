## Open risks to the plan

| Risk | Effect | Mitigation |
|---|---|---|
| Upstream features still maturing: composefs sealed images, systemd-pcrlock, btrfs fscrypt, hash-based module integrity | Some integrity features ship behind feature detection | Specs define the fallback for each (see the per-spec failure modes) |
| Interpreter `AT_EXECVE_CHECK` patches carried downstream | Maintenance cost in pkgs | Upstream the patches; unpatched interpreters only in workbenches |
| Rebuilder operators must be independent organisations | The k-of-n quorum is only as good as its operators | Launch with three operators and allow owners to add a personal rebuilder |
| Agent identity standards are still drafts | Adapters may need to change | Internal model is Biscuit + Cedar; adapters isolated in gate and aide |
| GPU native context support varies by vendor | Tier-2 GPU apps limited on some hardware | Hardware matrix in [Profiles and hardware](../01-overview/profiles-and-hardware.md) |
